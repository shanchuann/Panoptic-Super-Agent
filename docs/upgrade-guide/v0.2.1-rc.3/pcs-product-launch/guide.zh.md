# 使用 PCS 启动万象超级智能体

[English](guide.md) | 中文

## 变更

万象超级智能体的 Web 和桌面端默认使用 `~/.pcs` 作为数据目录。在源码仓库中使用 `pnpm pcs`，桌面端安装的终端命令为 `pcs`，桌面启动链接为 `pcs://open`。新安装包的文件名以 `pcs-` 开头。启动入口通过 `PCS_HOME` 指定其他数据目录。

## 迁移

1. 退出万象超级智能体 Web 和桌面端。如果原来使用默认的 `~/.panoptic-super`，且 `~/.pcs` 尚不存在，将 `~/.panoptic-super` 重命名为 `~/.pcs`。项目记录、配置和凭据会一起迁移。如果两个目录都存在，将 `PCS_HOME` 指向要使用的目录。
2. 在源码仓库中运行 `pnpm pcs web`，或打开万象超级智能体桌面端。进入「项目」和「模型」，确认已有项目和提供商设置已加载。
3. 如需安装桌面端终端命令，在应用中选择「管理 pcs 命令」，并在新终端中运行 `pcs --version`。将已有的 Panoptic 启动快捷方式改为 `pcs://open`。
