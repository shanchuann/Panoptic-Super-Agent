## 独立性

GitHub 仓库不是 fork，本地只有指向本仓库的 origin。工作区发布元数据指向本仓库，本仓库拥有单独的 Windows CI；第三方许可证与 vendor 归属记录保留。技术包名和 dsh CLI 保持现有兼容命名，DeepSeek 模型及账号服务仍按实际提供方标注。
