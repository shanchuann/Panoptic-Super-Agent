## 2. 排除清单（三件套）
| 排除项 | 为什么不做 | 什么条件下重新考虑 |
|---|---|---|
| 自由多智能体（群聊/自由协商，v0.1） | 15× token、失败集中在系统设计（F-07） | 受控拓扑（orchestrator/blackboard）按 M13 与 ADR-0006 分阶段启用；自由拓扑仅在单 agent 触顶且任务可并行时重议 |
| 开放网页/桌面 GUI 自主操作 | 真实站点成功率 ~64%；OSWorld 2.0 仅 20.6% | 有明确付费场景且确定性脚本覆盖不了 |
| 图谱/时序记忆 | 收益无第三方可复现评测，且成本高 | 出现多跳、时效性强的真实需求 |
| 多租户 SaaS / 计费 / 云端账号 | 本项目是开源个人工具：用户自带 API、本地运行，不存在租户隔离与计费需求 | **永久排除**；若未来做托管服务，另立项目与 ADR |
| 企业权限/审计（RBAC、SSO） | 验证阶段成本高于价值 | 进入企业交付 |
| 自研模型/微调 | 无数据与算力优势 | 现成模型在 held-out 上 <30% |
| 移动端 App | 与核心验证无关 | Web 版验证通过后 |
| 插件市场/A2A 跨 agent 协议 | 双边市场冷启动 | 单场景跑通且有人要接入 |
| 语音/多模态输入输出 | 非主场景刚需 | 场景明确需要 |
| 私有化部署 | 与个人用户定位冲突 | 企业客户要求 |

## 3. 边界与约束
- 架构：单 agent + 受控 subagent（只回摘要、无自由对话）；append-only 会话事件；**项目状态独立成域、不写 SessionHeader**；MCP 2026-07-28；模型网关统一入口；
- 安全：默认只读；三类动作审批；不可信内容不驱动高权限工具；凭证不入沙箱；
- 执行环境：**首版本地隔离**（OS 级文件/网络限制 + 工作区白名单），云沙箱后置到上线前评估；
- 时间/资源：单次运行 ≤30 分钟、步数与重试上限（已锁）；**不记预算、不计量费用**（用户开发完成后接入订阅使用）；
- 数据：单用户本地存储（无云端账号、无租户隔离）；除显式授权外不上传用户文件到第三方模型 API；
- 许可：优先 MIT/Apache-2.0；Claude Agent SDK 许可待核，不假设可商用。
