## 2. 排除清单（三件套：不做什么 + 为什么 + 何时重议）
| 排除项 | 为什么不做 | 什么条件下重新考虑 |
|---|---|---|
| 多租户 SaaS / 账号计费 | v0.1 无客户，先验证能力 | 有 ≥3 个外部用户愿付费 |
| 企业权限/审计体系（RBAC、SSO） | 成本高于验证价值 | 进入企业交付 |
| 自研模型/微调 | 无数据与算力优势 | 现成模型在 held-out 上 < 30% |
| 移动端 App | 与核心验证无关 | Web 版验证通过后 |
| 插件市场/生态 | 双边市场冷启动 | 单场景跑通且有人要接入 |
| 语音/多模态输入输出 | 非主场景刚需 | 场景明确需要 |
| 多智能体编排（v0.1） | 生产失败率高（F-07 待核），先单 agent | 单 agent 触顶且任务可分解 |
| 私有化部署 | 与个人用户定位冲突 | 企业客户要求 |

## 3. 边界与约束
- 单次任务最长执行时间：30 分钟（超时交回人工）；
- 单任务成本上限：¥10（硬熔断）；
- 数据：默认本地存储，不上传用户文件到第三方（除显式授权的模型 API）；
- 许可：优先 MIT/Apache-2.0 组件，商用友好。
