## 2. 排除清单（三件套）
| 排除项 | 为什么不做 | 什么条件下重新考虑 |
|---|---|---|
| 多智能体拓扑（v0.1） | 15× token、失败集中在系统设计（F-07） | 单 agent 触顶且任务可分解为独立并行子任务 |
| 开放网页/桌面 GUI 自主操作 | 真实站点成功率 ~64%；OSWorld 2.0 仅 20.6% | 有明确付费场景且确定性脚本覆盖不了 |
| 图谱/时序记忆 | 收益无第三方可复现评测，且成本高 | 出现多跳、时效性强的真实需求 |
| 多租户 SaaS / 计费 | 无客户，先验证能力 | ≥3 个外部用户愿付费 |
| 企业权限/审计（RBAC、SSO） | 验证阶段成本高于价值 | 进入企业交付 |
| 自研模型/微调 | 无数据与算力优势 | 现成模型在 held-out 上 <30% |
| 移动端 App | 与核心验证无关 | Web 版验证通过后 |
| 插件市场/A2A 跨 agent 协议 | 双边市场冷启动 | 单场景跑通且有人要接入 |
| 语音/多模态输入输出 | 非主场景刚需 | 场景明确需要 |
| 私有化部署 | 与个人用户定位冲突 | 企业客户要求 |

## 3. 边界与约束
- 架构：单 agent + 受控 subagent（只回摘要）；事件日志 append-only；MCP 2026-07-28；
- 安全：默认只读；三类动作审批；不可信内容不驱动高权限工具；凭证不入沙箱；
- 时间/成本：单任务 ≤30 分钟（A-07）、成本上限 ¥10 硬熔断（A-04 待确认）；
- 数据：默认本地存储；除显式授权外不上传用户文件到第三方模型 API；
- 许可：优先 MIT/Apache-2.0；Claude Agent SDK 许可待核，不假设可商用。
