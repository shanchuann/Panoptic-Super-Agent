# 评测、可靠性与产品化风险（研究截至 2026-11-05）

> 口径：【事实】= 有可核验来源；【推断】= 研究者判断。分数不可跨口径比较（同一基准在不同脚手架/版本下差异可达 40 个百分点）。
> 检索受限：github.com、huggingface.co、多数厂商定价页与部分安全报告站被反爬/网络策略拦截，相关结论已降级标注。

## ① 一页结论（7 条，每条附证据编号）

1. **公开基准已不能单独证明"可用"**：GAIA 头部提交 92.36%，已追平论文中人类 92%；SWE-bench Verified 头部 >70%，而更接近真实的 SWE-bench Pro 仅 23.3%（私有子集 14.9%–17.8%）。【事实 #1 #2 #3】
2. **长任务是断崖而非线性变难**：OSWorld 2.0 中 <45 分钟任务最好 20%–24%，137–163 分钟无模型超 10%，>163 分钟所有模型为 0。【事实 #4 #5】
3. **可靠性要用 pass^k，而不是 pass@k / pass^1**：τ²-bench 头部 pass^1 已 87.9%，但"同一任务 k 次全对"的概率才是产品判据；公开榜单几乎只报 pass^1。【事实 #6】【推断】
4. **失败主因是系统设计，不是模型能力**：7 个开源多智能体系统实测失败率 41%–86.7%，MAST 归纳 14 种失败模式（3 大类），人工标注 κ=0.88。【事实 #7】
5. **安全底线是"不可信内容不得直接驱动高权限工具"**：NVD 中提及 MCP 的 CVE 累计 156 条；EchoLeak（CVE-2025-32711，9.3，零点击数据外泄）与 mcp-remote（CVE-2025-6514，9.6，OS 命令注入）证明不是理论风险。【事实 #8 #9 #10】
6. **成本与可靠性同源**：最好成绩需约 244K 输出 token/任务（Opus 4.8），GPT-5.5 用 39K token 只到 ~14%；叠加 pass^k 重试后成本成倍放大。【事实 #4】【推断】
7. **市场已验证付费意愿、但高度同质化**：玩家含 Manus（已到 Manus 2.0）、Devin、Claude Code/Cowork/Managed Agents 与开源自托管的 OpenHands；Devin 定价 $20/$200 月 + $40/席位团队版。差异化只能来自"可验证的交付物 + 安全边界"，不是"能调工具"。【事实 #11 #17 #18】【推断】

## ③ 候选方案对比（"怎么证明能用"）

| 方案 | 做法 | 代价 | 风险 |
|---|---|---|---|
| A. 公开榜单跑分 | 跑 GAIA / SWE-bench Pro / TB 4.0 / OSWorld 2.0 / τ³ | 1–2 人周 + 数千元 API（推断） | 已饱和、可污染、与真实任务错位；对外好看、对内不可验收 |
| B. 自建金标准任务集 + 轨迹评估（推荐） | 20–40 条真实任务，人工写通过判据；跑 pass^3/pass^5；建回归集；轨迹打分 + loop 检测 | 2–4 人标注 2–3 周；每轮重跑成本×k | 任务集会过时；标注主观；pass^k 使成本×k |
| C. 第三方平台 + 外部红队 | LangSmith/Braintrust 接管 trace 与评分；聘红队打注入 | 平台费 + 审计费（万元级起，推断） | 供应商锁定；红队只覆盖已知攻击面 |
| D. 真实流量灰度 A/B | 真实用户任务，看成功率/接管率/成本 | 需流量与埋点；早期没有 | 失败成本由用户承担 |

**建议**：B 为内部验收主口径，D 上线后接续；A 仅用于对外沟通；C 在拿到第一批企业客户前不做。

## ④ 对本项目的启示

**现在必须定（否则后面返工）**
1. **五项验收判据**：任务成功率、pass^3、人工接管率、单任务成本上限、P95 完成时长。缺一项就无法回答"能不能用"。
2. **轨迹日志 schema**：每步记录输入摘要、工具名、参数哈希、结果摘要、token、耗时、是否重试。这是轨迹评估与 loop 检测的前提（#12 #13）。
3. **安全底线**：默认只读；"写文件 / 付款 / 对外发送" 三类动作强制人工审批；网页、邮件、文档、MCP 返回值一律标记不可信，不得直接驱动高权限工具；工具白名单 + 每工具最小权限 + 全量审计（#8 #10 #11）。
4. **预算口径**：单任务 token 预算 + 重试预算 + 美元上限，超限即中止转人工（#4 #6）。
5. **评测集起点**：先 20–30 条任务跑通"判据—执行—评分"闭环，再扩到 100+。

**可以后置**：选哪个公开基准对外报分；多智能体拓扑（MAST 显示系统设计类失败占大头，先做单 agent + 强验证）；模型档位与缓存优化（先用最强模型验证能力上限再降档）；定价与市场定位。

## ⑤ 未解决问题

1. **pass^k 的公开可比数据稀缺**：榜单普遍只报 pass^1，厂商不披露重复试验，无法给出行业平均 pass^5。
2. **Manus / Genspark 真实定价与毛利**：页面为 JS 渲染且抓取被拦，只能确认"订阅 + 积分 + 团队版"结构。
3. **2026 年在野间接注入事件规模**：CSA 研究报告页被 Cloudflare 拦截，取不到统计口径。
4. **"八大 agent 基准可在 2026-04 被 reward hack 到 ~100%"**：仅见二手转述，未找到原始论文，未采信。
5. **企业真实客单价与续费率**：无公开披露数据。
