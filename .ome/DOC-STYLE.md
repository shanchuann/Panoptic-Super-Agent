# 文档写作规范

本规范用于项目文档的修订。目标有两条：读起来像人写的专业文档，排版上不出现模板痕迹。

## 禁用字符

以下字符在项目文档中禁用，代码块与外部引用除外。

| 字符 | 原因 | 替代 |
|---|---|---|
| 箭头符号 | 模板感强，语义含糊 | 用“至”“到”或编号表达 |
| 间隔号 | 排版上显得零碎 | 用逗号或空格 |
| 直角引号 | 与正文中文引号不统一 | 用中文双引号 |
| 长破折号 | 常被用来制造停顿 | 断句或改用逗号 |
| 装饰性符号 | 表情、星号、勾选符号不承担信息 | 删除 |

## 写作要求

1. 直接陈述事实。删掉“值得注意的是”“不难发现”“综上所述”这类铺垫。
2. 句子长短交替。连续三句长度接近时，改写其中一句。
3. 一段最多一处加粗，标题与表头除外。
4. 不用“不仅而且”“不是而是”这类对仗句式。
5. 不写三段式排比。两项或四项都可以。
6. 不写空洞结尾。最后一句给出事实、下一步或结论。
7. 数字带口径与日期。找不到出处的数字不写。
8. 少用“赋能”“生态”“格局”“闭环”这类抽象词，用具体动作替代。
9. 引用外部结论时说明来源与证据等级，不把推测写成事实。
10. 表格用于对照，不用于堆砌句子。
