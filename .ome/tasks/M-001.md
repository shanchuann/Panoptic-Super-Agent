# M-001 记忆最小闭环（L0 证据 + L2 事实 + 显式读写删）

- **编号**：M-001
- **标题**：记忆子系统 M1（无衰减、无睡眠、无跨项目共享）
- **目标**：把"能记住、能召回、能证据下钻、能删除、能关闭"跑通；存储落在独立 `memory` 存储域，不改会话 JSONL。
- **输入**：[ADR-0005](../../docs/adr/ADR-0005-memory-weight-forgetting.md)、[memory.md §2–§10](../../.ome/design/memory.md)、[06-repo-seams.md §1–§3](../../.ome/research/06-repo-seams.md)
- **完成判据（可执行）**：
  1. `memory` 存储域 v1 创建成功，记录写入/读出通过 zod schema 校验；进程重启后数据仍在。
  2. 显式 `remember` 写入 5 条（各带 ≥1 条 L0 证据）至 新会话 `recall` 命中 ≥4 条。
  3. 每条召回结果带 `evidence_id`；`memory.evidence(id)` 返回证据摘要与原文句柄。
  4. `forget(id)` 后 60 秒内同一查询命中数为 0；主记录、索引、缓存同步清理（测试断言）。
  5. 配置 `enabled=false` 后：不写入、不注入；开启后恢复。
  6. 注入内容产生可重建记录（事件或宿主日志），且 `SESSION_FORMAT_VERSION` 仍为 4、会话 JSONL 字节格式未变（断言测试）。
  7. 新增/修改文件的测试通过；无新增 `as unknown`；`pnpm run typecheck` 通过。
- **验证器**：强（命令 + 断言测试）
- **写域**：`packages/<group>/memory/**`（新包）、`packages/bundle/base/cordis.patch.yml`、`tsconfig.host.json`、`.ome/evidence/M-001/`
- **依赖**：ADR-0005 Accepted（已完成）
- **不做**：权重衰减与 TTL（M-002）、睡眠整合（M-003）、项目隔离与跨项目共享（M-004）、向量库选型（先用 SQLite + FTS，向量列为可选后端）
- **资源**：L1（开发任务）
- **模型档**：中档（编码任务）
- **验收人**：Lead
- **证据目录**：`.ome/evidence/M-001/`（测试输出、存储检查、删除验证、格式断言）

## 实现要点

- 新包骨架与登记按 [06-repo-seams §7](../../.ome/research/06-repo-seams.md)：package.json（`dsh.bundle` 可选）、tsconfig references、`src/index.ts`（函数插件/Service）、locale、README、测试；
- 服务 `ctx.memory`：`remember / recall / evidence / forget / pin`；
- 工具：`memory_search`、`memory_write`、`memory_forget`（`memory_evidence` 可后置到 M-002）；
- 注入：`agent/pre-step` 中 `next()` 后追加带来源的 `UserMessage`；
- 事件：默认不写 session 事件；如需写，标 `ignorable` 并走持久化类型变更流程。
