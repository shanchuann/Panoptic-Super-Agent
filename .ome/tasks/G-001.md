# G-001 模型网关 MVP（路由 / 降级 / 计量 / 按角色分层）

- **编号**：G-001
- **标题**：统一模型入口与非对称模型策略
- **目标**：一个入口完成模型选择、降级、用量记录（不计费）；Lead/Verifier 用强模型、Worker 可用便宜模型，失败升级。
- **输入**：[ADR-0004](../../docs/adr/ADR-0004-model-gateway.md)、[projects.md §4](../../.ome/design/projects.md)
- **完成判据（可执行）**：
  1. `resolve(request) 至 Spec` 可用：返回 provider/model/能力声明/超时/降级链；非法请求（不支持的能力）明确报错而不是静默降级。
  2. 角色路由：同一任务下 Lead 与 Researcher 解析到不同档位的模型（测试断言），配置可覆盖。
  3. 故障降级：主模型返回超时/限流时按 fallback 链切换成功，并记录 `model/fallback` 事件。
  4. 用量记录：每次请求记录 provider/model/token（输入/输出/缓存）/耗时/步数/角色；可查询；不换算金额。
  5. 资源限制：超过时长/步数上限时返回 `limit_stopped`，保留中间产物。
  6. 升级策略：同一子任务连续失败 2 次后自动切换强模型重试（测试用例模拟失败）。
  7. 不改变基座 adapter 语义；`ModelSelection` 快照语义不变（回归测试）。
  8. BYOK 配置：设置页可填 baseURL、密钥（写凭据存储，配置只存引用名）、协议、三档模型映射；保存前连通性测试通过。
  9. 密钥安全：配置/日志/错误信息中不出现密钥；仅允许 https 或 localhost；自定义请求头白名单校验（自动化测试）。
- **验证器**：强（故障注入测试 + 断言）
- **写域**：`packages/llm/**`（网关包）、`packages/settings/**`（配置项）、`packages/bundle/base/cordis.patch.yml`、`.ome/evidence/G-001/`
- **依赖**：ADR-0004 Accepted（已完成）；建议在 P-001 之后接项目资源限制
- **不做**：多模态编码（先用能力声明占位）、缓存优化（另立 G-003，P2）、内置供应商预设（v0.1 只做 BYOK）
- **资源**：L1（需要少量真实调用验证降级）
- **模型档**：不适用（本任务实现路由）
- **验收人**：Lead
- **证据目录**：`.ome/evidence/G-001/`（路由断言、降级注入记录、计量样例、熔断用例）
