# P-001 项目域与状态机（Host service + 存储域）

- **编号**：P-001
- **标题**：项目实体、任务树、状态机、产物与审计（无 UI）
- **目标**：让"项目"成为可持久、可查询、可迁移的业务实体；会话只作为执行轨迹被引用。
- **输入**：[ADR-0003](../../docs/adr/ADR-0003-session-project-state.md)、[projects.md §1–§2、§9–§11](../../.ome/design/projects.md)、[06-repo-seams §4](../../.ome/research/06-repo-seams.md)
- **完成判据（可执行）**：
  1. `project` 存储域 v1（project/goal/task/task_dependency/run/artifact/audit_event）创建成功，重启后数据仍在。
  2. `ctx.projects` 服务提供 create/plan/assign/transition/complete/archive/export；命令均返回结构化结果。
  3. 状态机：合法迁移全部通过、非法迁移全部被拒（参数化测试覆盖至少 12 条迁移）。
  4. 任务依赖 DAG 校验：环被拒绝；`blocked_by` 未完成时不能进 `ready`（测试）。
  5. 产物登记带 `provenance`（runId、证据 id、版本、sha256）。
  6. 导出为 JSON 后可再导入（往返测试）；删除级联项目域并保留删除审计元数据。
  7. `SessionHeader` 与 `SESSION_FORMAT_VERSION` 未变（断言测试）；项目归属存域侧。
- **验证器**：强（命令 + 参数化测试）
- **写域**：`packages/<group>/project/**`（新包）、`packages/api/*-controller/**`（最小）、`tsconfig.host.json`、`packages/bundle/base/cordis.patch.yml`、`.ome/evidence/P-001/`
- **依赖**：ADR-0003 Accepted（已完成）
- **不做**：图谱 UI（U-001）、自然语言建项智能体（P-002）、并发调度器（P1.5，暂不建卡）、审批流（G-002）
- **资源**：L1（开发任务）
- **模型档**：中档
- **验收人**：Lead
- **证据目录**：`.ome/evidence/P-001/`（测试输出、状态机覆盖表、导出/导入样例）

## 实现要点

- 域与服务拆分遵循 capability seam：Service Definition（`ctx.projects`）/ Provider（存储域实现）/ Consumer（命令、UI、后续调度器）；
- 单点写入口：只有服务写状态，Run 在结束时回写；禁止 UI 直接改状态；
- 事件：项目事件写项目域审计表（`audit_event`），不写会话事件；引用会话时只存 `sessionId` + 事件序号；
- 归档接 `workspace/session-activity` 与 `workspace/session-stop`，每日对账任务标记 `blocked`。
