# P-003 本机执行账本、检查点与恢复

首个交付是一个项目在本机完成一项既有 DSH 工具能执行的代码任务。任务在独立测试工作区运行，使用无密钥模型夹具。选择经授权的单文件操作作为首个可核对副作用。输入为 [P-001](P-001.md)、[Agent Runtime 契约](../contracts/agent-runtime.md)、[能力授权](../contracts/capability-approval.md) 和 [ADR-0010](../../docs/adr/ADR-0010-runtime-loops-and-execution-ledger.md)。

| 子任务 | 交付 | 验收 |
|---|---|---|
| P-003a 本地 Run | 关联 Project、Task、Run 和 Session。通过现有 DSH 执行入口启动、审批、取消。将产物和验证结果回写任务 | 只在测试工作区修改指定文件。拒绝未授权动作与越界路径。同一任务无法启动两次活动 Run |
| P-003b 账本与检查点 | 执行前保存动作标识、目标、输入哈希、幂等键和已获授权。结果持久后记录提交。记录恢复所需的最后已知步骤与证据 | 模拟意图写入后尚未执行、写入成功但结果未知、已标记提交三个进程中断点。恢复判定见下表 |
| P-003c 重启与取消 | 重开项目可查看已完成、待核对与下一步。取消传播至本次运行拥有的子进程 | 只读步骤可恢复，取消后子进程退出。失败原因与验证证据可查询。回放现有 Session 兼容路径 |

| 注入点 | 期望行为 |
|---|---|
| 已登记意图，动作尚未执行 | 查询证据确认无副作用后，仍满足有效授权的动作允许执行 |
| 文件已写入，提交回执缺失 | 用文件状态和哈希核对。可确认已完成时补账，证据不足时显示待核对 |
| 账本已标记提交 | 读取已有结果，实际写入计数仍为一 |

每个子任务一个可撤销改动。新增行为先有可失败的测试，再补实现。计划验收命令是 `pnpm exec vitest run <实现时登记的 Run 与账本测试文件> --maxWorkers 1`，并增加 keyless 场景验证启动、崩溃与重启的完整路径。将实际测试路径和预期写入卡片。既有回归使用 [B-005](B-005.md) 的 Session 与 SDK 测试。

写域为项目 Run 数据、局部执行插件、审批适配、测试目录与证据。项目状态通过项目服务写入，Session 仍通过现有持久化接口管理。提交前由维护者复核授权、文件写域与恢复分支。完成证据放在 `.ome/evidence/P-003/`。
