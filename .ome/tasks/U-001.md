# U-001 图优先 UI：项目图谱 + 节点详情 + 收件箱（Web MVP）

- **编号**：U-001
- **标题**：默认看项目图，聊天记录降级为节点记录
- **目标**：用户不打开任何会话即可判断"做到哪、卡在哪、要我做什么"；点击节点看结果与证据，再点"记录"看聊天。
- **输入**：[interaction.md](../../.ome/design/interaction.md)、[ADR-0003](../../docs/adr/ADR-0003-session-project-state.md)、[projects.md §11](../../.ome/design/projects.md)
- **完成判据（可执行 / 可复核）**：
  1. 路由断言：项目主页默认渲染图谱画布；不存在"全局聊天页"路由（自动化测试）。
  2. 3 秒测试：5 名未接触用户中 ≥4 人能在 3 秒内说出"进行到哪、卡在哪、需要我做什么"（人工记录）。
  3. 结果可达：任一任务节点 ≤2 次点击看到结果、验收判据与产物（可复核走查表）。
  4. 过程可追溯：任一节点 ≤3 次点击看到该 Run 的会话记录（只读、可分页）。
  5. 状态一致：图谱投影与项目域状态 100% 一致（对账脚本，覆盖 10 个项目快照）。
  6. 收件箱：审批/阻塞/待验收/超时告警四类聚合，处理后条目消失（端到端用例）。
  7. 性能：200 节点首屏 ≤1s、状态更新 ≤1s（本地基准）；键盘可达、状态不只靠颜色区分。
  8. 产物双视图：任务节点可看到其产物（角标/子项，≤2 次点击），项目级产物库列出全部产物；两处读同一数据源（对账测试）。
  9. 侧栏三形态：展开 / 图标轨（<1100px 自动）/ 聚焦隐藏；切换项目 ≤2 次点击。
  10. 默认折叠：D1 视图下节点数 = 里程碑数 + 活跃任务数；Run/产物/验证默认收起；>40 节点自动聚合。
- **验证器**：强（对账脚本 + 路由/端到端测试）+ 弱（3 秒测试人工）
- **写域**：`packages/client/**`（新组件）、`packages/host/**` 或新投影包、`packages/api/**`（图投影接口）、`.ome/evidence/U-001/`
- **依赖**：P-001（项目域与状态）、interaction.md（已完成）
- **不做**：实时增量推送（U-002）、手动拖拽布局（U-002）、移动端（P3）；聚合折叠只做默认规则，交互式聚合在 U-002
- **资源**：L1（开发 + 本地渲染验证）
- **模型档**：中档
- **验收人**：用户 + Lead
- **证据目录**：`.ome/evidence/U-001/`（截图/GIF、对账输出、3 秒测试记录、性能数据）

## 实现要点

- 图投影由 Host 计算（nodes/edges/counts/version），Client 只读；布局在客户端计算（ELK/dagre），手动位置可选；
- 节点更新走增量 patch，禁止整图重绘（保持位置稳定）；
- 记录按需拉取（sessionId + seq 范围），不随图一起传；
- 客户端插件登记三处：`tsconfig.client.json` references、`packages/bundle/web-app/cordis.patch.yml` 行、`web-app/package.json` 依赖。
