# T-005 Research 场景的报告与回放

这张卡保留资料报告验收，排在首个本地代码任务和崩溃恢复之后。依赖 [P-001](P-001.md)、[P-003](P-003.md)与 [开发任务计划](../PLAN.md)。

使用现有 `dsh` profile 启动，由项目任务引用 Session。首轮使用固定网页夹具和无密钥模型回放，输入三份资料，产出一页带来源链接的报告。在项目详情可找到产物、版本与验证证据。复开 Session 后可查看同一执行轨迹。

计划验收以 `pnpm run test:snapshot <实现时登记的场景文件>` 运行 keyless 场景。核对三份资料各被读取一次，报告列出三条来源，产物引用与文件哈希一致。评测 T-006 在这个场景可运行后接入。写域为 research 场景的测试配置、专属夹具、产物回归和 `.ome/evidence/T-005/`。
