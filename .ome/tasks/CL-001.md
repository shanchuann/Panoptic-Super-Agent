# CL-001 腾讯云任务持久化试验

开工条件是 [P-001](P-001.md) 的本地建项、建任务和进程重启读回已通过，任务标识和验收判据字段已有测试。腾讯云使用现有 2 核 4 GB Ubuntu 实例，先检查版本、磁盘、内存和既有服务。部署细节见 [部署方案](../design/cloud-local-deployment.md)。

1. 本机先实现轻量 DSH profile 下的测试 API 与 SQLite 存储。只开放提交与查询，使用独立目录和测试凭证。每个请求提供幂等键，同一键且同一内容返回既有任务，同一键而内容不同返回冲突。
2. 本地通过后部署至腾讯云独立服务目录。验收输入使用合成任务，依次提交、重复提交、重启测试服务、查询。数据库保留同一任务标识、状态和验收判据。
3. 使用 SQLite 一致性备份，将副本恢复到独立数据目录，核对关键记录、条数和检索结果。记录部署提交、磁盘增长、重启耗时和恢复证据。

写域为调度服务的 API、队列存储、测试配置和 `.ome/evidence/CL-001/`。用独立测试服务账号与有限访问范围。验收保留一个可重跑的提交、重启与查询脚本，并记录其实际路径。执行器上线时间由 [CL-002](CL-002.md) 决定。
