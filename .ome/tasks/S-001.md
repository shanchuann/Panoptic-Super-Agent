# S-001 旁路智能体

- 编号：S-001
- 目标：实现共享主会话快照的只读侧通道，旁路消息不进入主线，支持显式带入。
- 输入：[design/side-agent.md](../design/side-agent.md)、[ADR-0011](../../docs/adr/ADR-0011-side-agent.md)、[contracts/side-agent.md](../contracts/side-agent.md)
- 完成判据：
  1. 侧栏可打开旁路线程，生成主会话快照并显示快照版本。
  2. 旁路提问与回复写入旁路记录，不写入主会话事件日志。
  3. 主 Agent 下一轮上下文不包含旁路消息，测试可证。
  4. 主线时间线、未读与滚动位置不受旁路影响。
  5. 旁路只调用只读白名单工具，写操作被拒绝。
  6. 带入主线需要二次确认，写入带来源与快照版本的注记。
  7. 旁路线程按项目隔离，跨项目读取失败。
  8. 删除线程级联删除消息、快照与待确认带入记录。
- 验证器：强（单元测试 + 端到端用例 + 隔离测试）
- 写域：client 侧栏、project 存储与 api、tests、.ome/evidence/S-001/
- 依赖：P-001、ADR-0011
- 不做：旁路写操作、跟随模式、多线程并行、跨设备同步
- 资源：L1
- 验收人：Lead
