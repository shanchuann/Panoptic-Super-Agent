# X-001 可演进性契约与升级演练

- **编号**：X-001
- **标题**：扩展点契约、版本兼容与升级演练（保证开发完成后仍可升级）
- **目标**：把“内核冻结 + 四层契约 + 状态迁移 + 升级证据”落成可执行的契约测试与演练；验证换 provider、加拓扑、加协议、加远程控制时不需要改内核。
- **输入**：[ADR-0007](../../docs/adr/ADR-0007-evolvability-contract.md)、[extensibility.md](../../.ome/design/extensibility.md)、[06-repo-seams](../../.ome/research/06-repo-seams.md)
- **完成判据**：
  1. 每个 seam 有一份契约测试：模型 adapter、tool provider、sandbox provider、memory provider、coordination strategy、interaction view；
  2. 演练 A（记忆后端替换）：仅换 provider 配置，memory 服务代码零改动；导出至导入至重建索引，Recall 掉点 ≤5pp；
  3. 演练 B（模型供应商替换）：仅改网关配置；契约测试与录制会话回放通过；
  4. 演练 C（新增协作模式）：仅注册 strategy，调度器与内核零改动；路由与审计可用；
  5. 演练 D（新增工具/MCP server）：仅注册工具，内核零改动；权限/审批生效；
  6. 演练 E（远程控制原型）：新增 Host 服务与配对鉴权，不改 agent 核心；鉴权/审计用例通过；
  7. 版本兼容：旧数据（project/memory 域）迁移后读写一致；旧版导出包被新版接受（或明确拒绝并提示）；
  8. 文档：升级流程、回滚步骤、契约清单写入 extensibility.md；每次升级留迁移报告。
- **验证器**：强（契约测试 + 演练脚本 + 回放回归）
- **写域**：`packages/<group>/` 契约测试与 provider 接口、`scripts/`（演练脚本）、`.ome/evidence/X-001/`
- **依赖**：ADR-0007 Accepted；建议在 P-001/M-001/G-001 之后执行（需要真实 seam）
- **不做**：具体远程控制/ GUI 功能实现（后续任务）、A2A 协议实现、企业身份体系
- **资源**：L1（开发 + 演练）
- **模型档**：不适用
- **验收人**：Lead
- **证据目录**：`.ome/evidence/X-001/`（契约测试输出、五类演练记录、迁移报告、回滚步骤）

## 实现要点

- 契约测试放各包 `tests/contract/`，用同一套 harness 跑所有 provider；
- 演练脚本可重复运行，输出结构化报告（JSON）供 CI/人工复核；
- feature flag 与影子模式先在 Test profile 演练，再进默认组合。
