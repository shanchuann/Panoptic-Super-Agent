# Y-001 阶段化生命周期（问询/任务/交付/迭代）

- **编号**：Y-001
- **标题**：四阶段生命周期与阶段门禁
- **目标**：把"问询 至 任务 至 交付 至 迭代"落成状态机与交互；问询门禁通过才进入任务；交付五件套一致；迭代继承已有资产。
- **输入**：[lifecycle.md](../../.ome/design/lifecycle.md)、[ADR-0008](../../docs/adr/ADR-0008-lifecycle-and-paradigms.md)、[projects.md](../../.ome/design/projects.md)
- **完成判据**：
  1. 问询门禁：Brief 确认 + ≥1 客观判据 + 排除清单非空，缺一不能进入任务阶段（测试）；
  2. 任务阶段操作：删除/改进/插入/改派/接管均写事件并触发影响评估（下游/关键路径/时长）；
  3. 交付门禁：五件套（代码/文档/截图/部署/版本号）同一次构建，冷启动测试通过；回滚点存在；
  4. 迭代：继承 Brief/Spec/记忆/产物/任务基线；只跑差异与受影响下游；继承率 ≥60%（20 条样本）；
  5. 阶段与项目状态映射无歧义（状态机测试）；
  6. 用户打扰只来自收件箱（无强制弹窗，端到端用例）。
- **验证器**：强（状态机测试 + 端到端用例 + 样本统计）
- **写域**：project 域扩展、client 阶段视图、prompts、tests、`.ome/evidence/Y-001/`
- **依赖**：P-001（项目域）、ADR-0008
- **不做**：任务范式路由（Z-001）、事件驱动（W-001）、移动端
- **资源**：L1
- **验收人**：Lead
- **证据目录**：`.ome/evidence/Y-001/`
