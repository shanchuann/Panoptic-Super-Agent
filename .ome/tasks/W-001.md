# W-001 事件驱动运行时 MVP（触发器 + Watchdog）

- **编号**：W-001
- **标题**：从用户触发到环境触发
- **目标**：项目事件/定时/Webhook/GitHub/IM（桩）触发任务；规则过滤 + 分诊 + 派发；订阅直通；进程内 Watchdog。
- **输入**：[runtime.md](../../.ome/design/runtime.md)、[ADR-0009](../../docs/adr/ADR-0009-event-driven-runtime.md)、[projects.md](../../.ome/design/projects.md)
- **完成判据**：
  1. 5 类触发源接入（其中 IM 用桩），触发记录 id/来源/判定/派发/结果；
  2. 规则层：白名单、签名校验、去重、限流生效（测试）；未签名/非白名单被拒绝；
  3. 分诊：20 条样本归属项目/任务判断 ≥85%；
  4. 订阅直通：后续事件直达率 ≥90%（模拟 PR 评论/话题回复）；
  5. Watchdog（进程内）：死循环、无进展、超时各 1 个用例被拦截并暂停/升级；
  6. "自动推送"经审批或项目显式授权（端到端用例）；
  7. 全双工：长任务执行中可插话/暂停/取消（端到端）。
- **验证器**：强（触发/过滤/分诊/Watchdog 用例 + 样本统计）
- **写域**：新 runtime 包、project 事件接入、api、tests、`.ome/evidence/W-001/`
- **依赖**：P-001（项目域）、ADR-0009；建议在 U-001 之后（有图/看板可见）
- **不做**：存算分离（P2）、独立 watchdog 服务（P1.5）、A2A
- **资源**：L1
- **验收人**：Lead
- **证据目录**：`.ome/evidence/W-001/`
