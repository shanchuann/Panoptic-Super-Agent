# 架构图交付文件

正式架构图源为 [architecture-overview.svg](../architecture-overview.svg)，说明书使用同一文件。delivery 目录不再保存字节相同的 SVG 副本。

- [delivery/fig.pptx](delivery/fig.pptx)：原生可编辑演示文稿。
- [delivery/fig.pdf](delivery/fig.pdf)：独立 PDF 图件。
- [delivery/fig.pptx-report.json](delivery/fig.pptx-report.json)：导出质量报告。
- [delivery/selection.md](delivery/selection.md)：选定版本记录。
- [brief.md](brief.md)：图件简报。
- [ATTRIBUTION.md](ATTRIBUTION.md)：来源与归属，随图件保留。

A/B 候选、工作包副本、对照页和预览截图不参与说明书构建；正式 SVG、PPTX 与 PDF 是本目录维护的交付内容。
