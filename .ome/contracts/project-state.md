# 项目状态契约

## 目的

定义项目域中的实体、标识、状态与不变量。项目域是协作状态的唯一权威，会话事件只作为执行轨迹。

## 实体

| 实体 | 关键字段 | 说明 |
|---|---|---|
| Project | id、名称、目标、状态、工作区、预算、创建时间 | 产品主实体 |
| Conversation | id、projectId、标题、状态 | 项目内的对话线程，不是状态权威 |
| Goal | id、projectId、描述、状态 | 阶段性结果 |
| Task | id、projectId、goalId、目标、判据、状态、依赖、角色、资源上限 | 最小执行单元 |
| Run | id、taskId、执行体、模型、状态、检查点、用量 | 一次尝试 |
| Artifact | id、projectId、路径、版本、哈希、来源 | 交付物 |
| Evidence | id、来源类型、引用、时间、保留期 | 支撑结论的材料 |
| Approval | id、动作、目标、风险、证据、决策 | 审批记录 |
| Decision | id、内容、理由、有效时间、替代关系 | 已确认决策 |

所有实体带 commandId、correlationId 与 actor，用于审计与恢复关联。副作用实体另带 idempotencyKey。

## 状态机

项目：草案、问询、规划、执行、暂停、验证、已交付、迭代、归档、失败。
任务：待办、就绪、已分配、执行中、等待输入、等待审批、验证中、完成、失败、阻塞、取消。
运行：排队、准备、执行、暂停、成功、失败、资源停止、取消、超时。
产物：草稿、候选、已验证、已交付、退回。
审批：请求、批准、拒绝、过期。

迁移规则见设计文档第五章。非法迁移返回结构化错误并写入审计。

## 不变量

1. 任务必须有目标与至少一条验收判据，否则不得进入就绪。
2. 同一任务同一时刻最多一个活动运行。
3. 产物不可修改，只能生成新版本。
4. 审批绑定动作哈希与证据引用，动作变化后原审批失效。
5. 项目域写入只通过服务层，界面只读投影。
6. 事件只追加，不修改历史。
7. 删除项目级联清理记忆命名空间与索引，保留删除审计元数据。
8. 跨项目引用必须显式授权，默认不可见。

## 验收

创建项目后可跨进程恢复活动任务；非法迁移全部拒绝；删除后子实体与索引不可检索。
