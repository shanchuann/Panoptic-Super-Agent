# 本地项目主对话

Panoptic 桌面和本地 Web 通过侧栏的「项目书架」进入项目选择页。书脊可展开预览，确认打开后恢复该项目的主对话。书架中的「新项目」打开目录选择或创建流程。关系图占据主工作区，缩放控件位于展开的侧栏内，主输入框沿用原布局，居中停靠底部并支持调宽。悬停查看节点状态和来源，点击进入只读对话记录并定位关联回合。「引用节点」返回图谱，将节点信息和来源记录添加到同一项目的主对话草稿。右侧栏仍通过原入口打开和收起。项目域以工作区 ID 保存主 Session 的预留标识。Host 先保存预留，再创建或恢复该标识对应的 Session。重复打开、并发打开和创建途中失败后的重试使用同一个标识，工作区改名也会保留它。

Panoptic 的产品入口将项目、会话、配置、技能和模型凭证定位到 `~/.pcs`。桌面注册 `pcs://`，从项目图谱开始。模型使用在 Panoptic 设置中配置的独立 API Key。

对话内按请求选择执行方式。解释和状态查询直接回答，允许读取证据。明确且局部的小改动使用现有文件工具和验证，省略正式计划。多步骤工作先保存带验收条件的有序计划。项目状态保留计划版本，验证引用同一个 Session 中当前版本建立后产生的实际工具结果和摘要哈希。证据登记供用户核对，验收由对应判据决定。

活动计划、约束、有效项目决策和待核对操作会随同项目上下文进入后续请求。用户指示记住或撤销的决定带有源事件号和记录时间，同名键的最新版本生效。撤销使记录停止注入后续请求，历史 Session 仍按原有保留规则保存。项目上下文按主会话身份查找，其他项目和辅助会话各自独立。

授权范围内的文件操作由 DSH 文件策略和沙箱校验。项目外写入及副作用不透明的工具单独请求确认。Host 在执行前保存操作标识与参数哈希，有成功结果时记录返回。待核对操作会阻止新的有副作用调用。恢复时，受支持的本地文本写入可以根据目标文件的大小和 SHA-256 核对期望内容。已核对且文件仍匹配时，重复写入请求会在执行前结束。证据不足时保留待核对状态，由用户查看证据并批准结束核对。批准结束核对本身只更改项目记录。

本地首段涵盖固定工作区、顺序计划、项目决定和单文件恢复路径。独立 Run 生命周期、完整 DAG、跨项目知识复用和云端调度使用各自的后续验收条件。来源见 [项目域实现](../../packages/workspace/workspace/src/projects.ts) 与 [会话接入](../../packages/api/session-controller/src/project-conversation.ts)。
