# 记忆生命周期契约

## 目的

定义记忆的分层、作用域、类型、来源、有效性与生命周期，以及写入、冲突、检索与删除规则。

## 维度

| 维度 | 取值 |
|---|---|
| 层级 | L0 证据、L1 情节、L2 事实、L3 概念、L4 画像 |
| 作用域 | 全局、项目、任务、执行体 |
| 类型 | 事实、决策、偏好、流程、情节、教训、约束 |
| 来源 | 用户陈述、工具观测、文档、模型推断 |
| 有效性 | 活动、被替代、无效、归档 |
| 生命周期 | 候选、活动、被替代、无效、归档、删除 |

## 记录字段

记录包含标识、层级、作用域、类型、内容、置信度、来源与证据标识、有效时间、记录时间、替代关系、保留策略与删除状态。

## 写入

事件与产物先形成候选，经证据校验、作用域分类、去重、冲突判定后进入活动或被替代。模型推断必须与用户陈述、工具观测区分，不得同等信任写入。

## 冲突与有效性

同一主语与谓语出现新值时，旧值标记为被替代并记录替代关系与失效时间。无法判断新旧时两条并存并标记冲突。事实有效性、检索相关性与保留策略分开建模。

## 作用域隔离

项目记忆默认不可跨项目检索。跨项目复用必须经过显式共享策略，不由语义相似度决定。执行体只能访问被授权的项目与任务范围。

## 保留与真实性

用户要求记住表示更强的保留承诺，不表示事实永远正确。保留策略决定保留多久，有效性决定是否应当注入，热度只影响排序。

## 检索

向量、全文与实体三路召回，先融合再精排。注入前对同一主谓只保留最新有效版本，冲突项带标记。

## 删除

删除级联清理主记录、索引、嵌入与缓存，写入删除审计但不保留内容。删除后短时间内不可检索。

## 验收

删除后检索为零；替代链可追溯；跨项目检索为零；冲突被标记而非静默覆盖。
